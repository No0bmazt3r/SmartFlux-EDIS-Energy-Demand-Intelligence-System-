# SmartFlux EDIS: Design System

| | |
| --- | --- |
| Version | 1.0 |
| Theme | Dark only for the hackathon (light theme on the roadmap) |
| Source | The team's SmartFlux EDIS palette board and the "Purple" palette (Creative Booster) |
| Applies to | Owner app (mobile PWA) and Admin web (desktop) |

---

## 1. Principles

1. **The verdict first.** Every screen leads with one decision in plain words and a RM figure. Detail is one tap away.
2. **Evidence is part of the product.** The Evidence view is a first-class screen, not a debug panel.
3. **Calm by default.** Purple and neutral carry the interface. Orange is kept for what needs attention: peak energy, money at stake, and the primary action.
4. **Never colour alone.** Every status has text and an icon as well as a colour.
5. **Thumb first on mobile.** Primary actions sit in the bottom half; touch targets are at least 44 × 44 px.

### 3.1 Contrast check (WCAG 2.2 AA)

Text needs 4.5:1 (3:1 for large text, 24 px or 18.66 px bold); UI components and graphics need 3:1 ([WebAIM](https://webaim.org/articles/contrast/), [MDN](https://developer.mozilla.org/en-US/docs/Web/Accessibility/Understanding_WCAG/Perceivable/Color_contrast)).

| Foreground | Background | Ratio | Result |
| --- | --- | --- | --- |
| `--text` `#F3EEFA` | `--bg` `#0F061E` | 17.3 | Pass AAA |
| `--text` | `--surface` `#1C1230` | 15.6 | Pass AAA |
| `--text` | `--surface-2` `#2A1F42` | 13.4 | Pass AAA |
| `--text-muted` `#A69FB0` | `--surface` | 7.0 | Pass AAA |
| `--primary-text` `#C89CEC` | `--surface` | 8.0 | Pass AAA |
| `--secondary` `#FF9100` | `--surface` | 7.9 | Pass AAA |
| `--tertiary` `#FFC880` | `--surface` | 11.7 | Pass AAA |
| `--success` `#5EE0A0` | `--surface` | 10.7 | Pass AAA |
| `--danger` `#F28B82` | `--surface` | 7.5 | Pass AAA |
| White | `--primary` `#9D4EDD` | 4.6 | Pass AA |
| `--text-on-accent` `#0F061E` | `--secondary` `#FF9100` | 8.7 | Pass AAA |
| `#1F102C` | `--primary-soft` `#DCBFF3` | 10.9 | Pass AAA |
| `--outline` `#797284` | `--surface` | 3.9 | Pass (UI 3:1) |
| `--primary` `#9D4EDD` | `--surface` | 3.9 | **Text fails**; OK for fills, icons and borders. Use `--primary-text` for purple text |
| Primary-400 `#B375E4` | Secondary `#FF9100` | 1.4 | Adjacent chart segments need a 2 px gap |

## 4. Typography

| Role | Family | Weights | Use |
| --- | --- | --- | --- |
| Headline | **Plus Jakarta Sans** | 600, 700, 800 | Screen titles, verdicts, big numbers |
| Body | **Inter** | 400, 500, 600 | Paragraphs, card text, tables |
| Label / data | **JetBrains Mono** | 400, 500 | Labels, chips, IDs, SQL, log lines, tabular figures |


| Token | Size / line height | Family, weight | Example |
| --- | --- | --- | --- |
| `display` | 40 / 48 | Jakarta 800 | RM502.75/month on the Energy plan |
| `h1` | 28 / 36 | Jakarta 700 | Screen title |
| `h2` | 22 / 28 | Jakarta 700 | Card verdict |
| `h3` | 18 / 24 | Jakarta 600 | Section title |
| `body` | 16 / 24 | Inter 400 | Card text (never smaller on mobile) |
| `body-sm` | 14 / 20 | Inter 400 | Secondary text |
| `label` | 13 / 16 | JetBrains Mono 500, +0.02em | Chips, badges, table headers |
| `mono` | 13 / 20 | JetBrains Mono 400 | SQL, log lines |

Numbers in tables and KPIs use `font-variant-numeric: tabular-nums`. Malay strings run about 20–30% longer than English: never fix text widths.

## 5. Layout, spacing and shape

| Token | Value |
| --- | --- |
| Spacing scale | 4, 8, 12, 16, 20, 24, 32, 40, 48 px |
| Mobile gutter | 16 px |
| Card padding | 16 px (mobile), 24 px (desktop) |
| Radius | `sm` 8 px (chips, inputs), `md` 12 px (buttons), `lg` 16 px (cards), `xl` 24 px (sheets, swatch tiles), `full` (icon buttons, nav pill) |
| Elevation | Dark UI uses lighter surfaces, not shadows: `surface` → `surface-2` → `surface-3`. One shadow for sheets: `0 8px 24px rgb(0 0 0 / .4)` |
| Grid (Admin web) | 12 columns, 24 px gap, max width 1280 px |
| Breakpoints | Mobile < 600, tablet 600–1023, desktop ≥ 1024 |
| Touch target | ≥ 44 × 44 px |

These follow the palette board.

| Component | Spec |
| --- | --- |
| **Button: Primary** | `--primary-soft` fill, `#1F102C` text, radius `md`, height 44, label in Inter 600 |

| **Button: Outlined** | Transparent, 1 px `--outline` border, `--text` |

| **Progress bar** | 6 px track `--surface-3`; fill `--primary-soft` (progress), `--tertiary` (savings), `--secondary` (peak share) |
| **Bottom navigation** | Floating pill on `--surface-2`, radius `full`; 4 items (Home, Ask, Machines, Approvals); active item is a `--primary-soft` circle with dark icon; Approvals shows a count badge |
| **FAB** | 48 px square, radius `md`, `--tertiary-700` fill (`#AD8857`), **dark** icon `#0F061E` (6.0:1; a light icon would fail at 2.9:1). Used for "Ask" on Home |
| **Label chip** | `--primary` fill, white text, leading icon, radius `sm` |
| **Icon buttons** | 36 px circles: magic (`--primary-soft`), group (`--secondary-300`), tag (`--tertiary`), delete (`--danger`), each with a dark icon and an `aria-label` |
| **Decision card** | `--surface`, radius `lg`; label chip (decision type), verdict (`h2`), RM figure (`display` in `--tertiary` for savings or `--secondary` for waste), confidence badge, ruled-out list, "Show evidence" link in `--primary-text` |
| **Briefing card** | Gradient `#5A189A` → `#3C096C`, `--text`; date in mono; 3 bullet lines; "Open" inverted button |
| **Risk badge** | Mono label + icon: read-only (eye, muted), advisory (lightbulb, primary-text), operational (wrench, tertiary), financial (payments, secondary) |
| **Status badge** | verified (check, success), awaiting approval (hourglass, tertiary), rejected (close, danger), not achieved (error, danger), unresolved (help, muted) |
| **Agent timeline** | Vertical list; each row: agent name (mono), action, arrow to target agent, status badge, model chip; `needs_revision` rows get a left 3 px `--tertiary` bar plus "Sent back" text |
| **Evidence block** | SQL in mono on `--bg` with a copy button; calculator inputs and outputs as a two-column table |
| **Table (Admin)** | Header in `label`; rows 48 px; zebra with `--surface` / `--surface-2`; numbers right-aligned, tabular |

Icons: Material Symbols Rounded, 24 px, weight 400.

## 8. Data visualisation

| Series | Colour | Also encoded by |
| --- | --- | --- |
| Peak kWh | `--chart-peak` `#FF9100` | Label "Peak" and position (top segment) |
| Off-peak kWh | `--chart-offpeak` `#B375E4` | Label "Off-peak" |
| Solar generation | `--chart-solar` `#FFC880` | Dashed outline area |
| Baseline / expected | `--chart-baseline` `#A69FB0` | Dashed line |
| Faulty machine | `--danger` | Marker + label, never colour alone |

Rules: label series directly where possible instead of a legend; 2 px `--surface` gap between stacked segments; error bars on per-machine kWh; axes and gridlines in `--chart-grid`; every chart has a one-sentence text summary above it (it doubles as the accessible description).

## 9. Accessibility checklist

- [ ] All text pairs from §3.1; no purple `#9D4EDD` text on dark surfaces
- [ ] Focus visible on every interactive element; logical tab order on Admin web
- [ ] Touch targets ≥ 44 px; bottom nav items ≥ 48 px
- [ ] Status and risk always use icon + text + colour
- [ ] Charts have a text summary and table fallback (Admin web "View as table")
- [ ] Respects `prefers-reduced-motion`
- [ ] `lang="ms"` set on Malay content
- [ ] Icon-only buttons have `aria-label`
- [ ] Usable at 200% zoom and at 360 px width
